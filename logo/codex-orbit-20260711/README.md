# Codex orbit concept

This Giti mark combines a planetary orbit, a three-node Git graph, and a living
leaf. Coral and green suggest removed and added lines; violet is the orbital
accent.

- `giti-logo.png` is the transparent final asset.
- `giti-logo-source.png` preserves the generated chroma-key source.
- `giti-logo-circles.png` is the revised transparent mark with three circular
  tree nodes and no leaf.
- `giti-logo-circles-source.png` preserves that revision's chroma-key source.

Generated with the built-in image tool, then converted locally from a flat
magenta background to an alpha PNG.
